# DPE Permanent Memory Orchestration

DPE Skills does not include an automatic-memory runtime and does not enable memory hooks. A general task or the phrase DPE Skills does not authorize persistent memory writes.

1. Confirm the user actually requested a memory update and inspect the host's supported write mechanism and storage constraints. Reuse an already authorized destination; ask only for a necessary missing decision.
2. Save a concise verified decision, plan, project fact or lesson. Include its evidence/date and distinguish superseding corrections from historical facts. Skip trivial chatter, speculative conclusions and duplicate notes.
3. Never save secrets, customer payloads, raw transcripts or credentials. Link artifacts instead of copying private content into a general/public library.
4. Use only the host-supported memory mechanism. Do not invent or run a `dpe remember` command; no such command is bundled. Do not change global configuration, create an external vault or transmit notes without authorization.
5. Verify the write succeeded, preserve unrelated content and report the actual saved path/status. If the host cannot persist it, provide a copy-ready note and say it was not saved.

A user-requested handover file is a task artifact; durable personal memory is a separate action governed by the host. Do not overwrite previous notes or move storage implicitly.
